# 回放护盾 v1.2.0

保留队名、队标与完整比赛画面。隐藏页面比分、胜负高亮，以及播放器周围的剧透线索。

## 升级已安装的版本

如果之前安装过旧版，将本仓库的 `extension` 文件夹内容覆盖到原安装目录后：

1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 找到「回放护盾」，点击卡片上的重新加载按钮。
3. 刷新所有已打开的 B 站页面，清除旧版注入的样式和视频遮挡。

如果原来是从其他位置解压并安装的：用新版文件覆盖原来的 extension 文件夹，再重新加载；或移除旧扩展，改为加载本包的 extension 文件夹。不要同时运行两个版本。

旧版的严格队名隐藏、视频遮挡及相关设置均不再使用；旧版「隐藏周边剧透」的开关状态保留。新增的事件图标保护和总局数保护默认开启。

## 首次安装

解压 ZIP，打开扩展管理页，开启「开发人员模式」，点击「加载解压缩的扩展」，选择直接包含 manifest.json 的 **extension 文件夹**。然后刷新 B 站页面。

## 页面比分

打开 [官方直播间 / 赛事页](https://live.bilibili.com/6)，按队名和日期找到比赛，点击原有「回放」按钮。赛程卡片与晋级树的队名、队标都显示；比分用「—」代替，胜负颜色统一。MVP 评分、胜方标记及积分表仍隐藏。

## 保护开关与 UP 主筛选

点击页面右下角「◈ 护盾」或浏览器工具栏中的扩展图标：

- **隐藏周边剧透**：隐藏标题、简介、推荐、评论、网页弹幕、进度和总时长。保留播放 / 暂停、±15 秒、+2 分钟和倍速控件。
- **隐藏进度条事件提示**：隐藏击杀、龙、塔等事件图标所在的独立标记层，同时隐藏高能曲线与章节 / 事件预览。即使关闭周边隐藏，这个开关也单独生效。
- **隐藏总局数线索**：始终隐藏原生上一集、下一集、选集列表、播放器选集菜单及结束推荐。无论当前是 P1、P3 或最后一局，都隐藏相同的原生控件。
- **仅保护赛事官方 UP 主**：按视频上传者 mid 判断。默认名单为 `50329118`（哔哩哔哩英雄联盟赛事），可在面板输入框中修改，多个 mid 用逗号分隔。赛事页 `live.bilibili.com/6`、`/blanc/6`、`/h5/6` 与 `/v/game/match` 始终启用；`player.bilibili.com` 外部播放器和 `blackboard` 活动页始终启用；直播页不启用。名单留空时回退为全部视频页保护。

当前页 UP 主不在名单时，右下角「◈ 护盾」显示为灰色，面板顶部标注当前 UP 主 mid 与“未启用”，把该 mid 加入名单后当前页立即生效。UP 主信息来自页面上传者链接，缺失时回退到 JSON-LD 的 author，不产生额外网络请求。

护盾面板里的「上一局 / 下一局」始终保持相同的文字、显示和可点击状态，不显示总局数，不因到达末局而变灰或消失。点击时使用同一视频里实际存在的分集链接，或者原生切局处理；没有可用入口则不跳转。它不生成不存在的下一局，也不会拼出越界分 P 地址。

固定按钮解决的是“还没点就能从按钮消失知道已经结束”的线索。实际点击后没有新内容、已经看完三局的战绩等，仍然可能让人判断系列赛已结束。

「临时显示页面比分」只显示比分和页面胜负样式，10 秒后恢复；再次点击可提前恢复。事件图标、周边保护和总局数保护不随它解除。

## 隐私与范围

设置只存在浏览器本地，仅申请 storage 权限，不读取 Cookie、账号或浏览历史，不上传数据。正常播放和点击下一局仍会由 B 站网页执行正常的网络请求。

支持电脑端 Edge / Chrome 中匹配的 B 站官方赛事页和回放页，不适用于手机 App。页面改版、图片中烧录的结果、新版独立弹幕组件可能需要后续适配。保留所有队名是有意的产品选择，因此后续晋级对阵中的队伍身份也保持可见。

## 预览和验证

`demo/index.html` 使用虚构队伍和合成画面，载入同一套实际保护代码；它不会跨页面保护 B 站。刷新已经打开的预览页可以看到新版。

规则核对自官方赛事组件和公开播放器资源。新增 progress-freezone、progress-point-wrap、PBP、ctrl-next / ctrl-prev 等规则已核对官方播放器模块。自动检查覆盖队名可见、比分隐藏、事件标记独立隐藏、固定切局按钮以及旧设置兼容；完整真实回放与全屏没有实测确认，详情见 [验证记录](VERIFICATION.md)。

源码在 extension 文件夹，无需安装依赖或运行构建。
