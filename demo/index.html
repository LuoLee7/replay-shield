03 / 安装或升级

刷新扩展，再刷新 B 站。

01

打开扩展管理

Edge 地址栏输入 edge://extensions
Chrome 输入 chrome://extensions

02

加载或重新加载

首次使用：开启开发人员模式，加载本目录的 extension 文件夹。已经安装本目录：点击扩展卡片上的重新加载。

03

刷新 B 站页面

旧版队名隐藏和视频遮挡已移除。刷新页面清除旧版注入，再按队名找到要看的比赛。
